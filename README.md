# Genz-Mart A Full-Fledge E-commerce Web App with AI featured powered by Next.js & Node.js

## ⚙️Tech Stack

- Typescripts
- Next.js
- Node.js
- Supabase
- NextAuth.js
- GraphQL
- Material UI
- Shadcn UI
- Ant Design
- Motion.dev
- Socket.io
- Cloudflare
- AI Chatbot (Grok AI)

## How to Run Frontend (Main UI & Admin UI)

1.  **Install packages:**
    npm install
2.  Create .env.local
    Set Environmental Variables
3.  **Run the project:** from both directory terminal
    npm run dev
4.  Open `http://localhost:3000 & http://localhost:3001
